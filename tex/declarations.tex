\subsection*{Data availability}
All code and data supporting the results of this paper are openly available
in the public GitHub repository \url{https://github.com/creelie/H8}. The
version that accompanies this paper is release v2.0.0,
\begin{center}
\url{https://github.com/creelie/H8/releases/tag/v2.0.0},
\end{center}
archived on Zenodo under the version DOI \zenodoVersionDOI. All versions of
the repository are gathered under the concept DOI \zenodoConceptDOI, which
always resolves to the latest one; the first release, v1.0.0, has the version
DOI \zenodoFirstDOI. The repository contains the programs that carry out the
computations of \Cref{sec:verification}, one for each item, with a README
that lists them by item; the Lean~4 certificate of \Cref{sec:lean}; the
Macaulay2 computations of local $\Ext$ algebras, with their output; the
sources of this paper; and the generators and TikZ sources of every figure.
The programs perform $2004$ checks, all of which pass, and the Lean kernel
checks one hundred and ten theorems, each depending on no axiom or on propositional
extensionality alone. The code and the computations were written and run
with the assistance of Claude Code. Every result they certify can be
reproduced from the repository with the programs and the Lean kernel, and the
authors are responsible for the mathematical statements and their proofs. No
other data were generated or analysed.
