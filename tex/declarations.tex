\subsection*{Data availability}
All code and data supporting the results of this paper are openly available.
The verification package comprises the Python scripts of
\Cref{sec:verification}, the Lean~4 certificate of \Cref{sec:lean}, the
Macaulay2 computations of local $\Ext$ algebras with their transcripts, and the
generators and TikZ sources of every figure. It is held in the public GitHub
repository \url{https://github.com/creelie/H8}, where it was developed on the
branch \texttt{claude/\allowbreak hodge-\allowbreak conjecture-\allowbreak
obstructions-\allowbreak 2z0lla}. The version that accompanies this paper is
release v1.0.0 of that repository,
\begin{center}
\url{https://github.com/creelie/H8/releases/tag/v1.0.0},
\end{center}
which is archived on Zenodo under DOI~\zenodoDOI,
\begin{center}
\url{https://doi.org/10.5281/zenodo.22950276}.
\end{center}
Running \texttt{python3 code/verify\_all.py} prints
\texttt{951 checks passed, 0 failed}. Running
\texttt{lean HodgeObstruction.lean} checks eighty theorems, each of which uses
no axiom or propositional extensionality alone. The Python computations and the
Lean formalisation were carried out with the assistance of Claude, an AI system
developed by Anthropic. Every result they certify is reproduced from the
repository by the scripts and by the Lean kernel, and the mathematical
statements and their proofs are the responsibility of the authors. No other
data were generated or analysed.
